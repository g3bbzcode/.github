# G3bbz Code

**Turkish-first AI agents that actually do the work.**
*Türkçe konuşan, gerçekten iş yapan yapay zekâ ajanları.*

We build AI agents that work in your browser and on your desktop, and that speak natural Turkish. We also build the tools to measure how well they do it. Everything here comes out of a real daily-use assistant, not a demo.

## What we're building

| Project | What it is | Status |
|---|---|---|
| **TR-AgentBench** | A native Turkish benchmark for tool-using AI agents: browser tasks, desktop tasks, safety (asks before paying or sending), and handling ambiguous requests. It is written from real requests, not translated from English. | 🛠️ In progress |
| **Browser Bridge** | Lets an agent work inside the user's own browser, with their logged-in sites, by reading the page structure instead of screenshots. | 🛠️ In progress |
| **Turkish Voice Kit** | Local Turkish speech recognition, speech synthesis and wake word. Runs offline, no GPU required. | 🗓️ Planned |
